\section{Q1. Diferenciar as Camadas 2 e 3 do modelo OSI e indicar os protocolos utilizados para endereçamento nestas camadas.}
\label{q1}

\subsection{Camada 2: Camada deEnlace de Dados}
A Camada de Enlace de Dados observa defeitos e corrige se necessário no pacote~\cite{tanenbaum2003redes}. É nessa camada que é definida e topologia, e nela que há o funcionamento dos switches de camada 2~\cite{tanenbaum2003redes}.
Além disso, nessa camada é feito o controle de fluxo, para garantir que o emissor não envie dados rápido de mais para o receptor~\cite{tanenbaum2003redes}

Os protocolos mais utilizados são Ethernet e Wi\-fi, mas existem outros protocolos, como o token ring, FDDI (Fiber Distributed Data Interface), PPP (Point\-to\-Point Protocol), entre outros~\cite{tanenbaum2003redes}.

O protocolo de endereçamento desta camada é o próprio Ethernet, que define o formato do frame com os campos de endereço MAC de origem e destino~\cite{CNN2026Lamix}. Os endereços MAC são físicos e permanentes, inerentes a cada dispositivo (computador, celular, etc.)~\cite{CNN2026Lamix}, e ficam associados às portas dos switches por meio da tabela MAC, conforme a Figura \ref{fig:q1_mac_table}

\subsection{Camada 3: Camada de Rede}
Na camada de Rede, o protocolo responsável pelo endereçamento é o IP (Internet Protocol, nas versões IPv4 ou IPv6), que atribui a cada dispositivo um endereço lógico e envia os dados em datagramas, sem garantia de entrega: os datagramas podem chegar desordenados, duplicados ou mesmo não chegar~\cite{wikipedia2026ip}. O IP também permite o agrupamento dos dispositivos em sub-redes por meio do mascaramento, conferindo mais organização e segurança ao isolar máquinas em segmentos distintos~\cite{wikipedia2026subnet}.

Além do IP, essa camada conta com protocolos de suporte à comunicação, como o ICMP, empregado no diagnóstico de falhas entre dispositivos (como o comando \texttt{PING}, baseado em mensagens \texttt{Echo Request} e \texttt{Echo Reply}), e com protocolos de roteamento, como o RIP e o OSPF, responsáveis por definir o caminho percorrido pelos dados entre redes distintas~\cite{RIPandOSPF}. O RIP utiliza o número de saltos como métrica, sem considerar o atraso de cada trecho, enquanto o OSPF baseia-se no algoritmo de Dijkstra para calcular o caminho mais curto~\cite{RIPandOSPF}. É também nessa camada que operam os switches de camada 3, responsáveis por interligar sub-redes distintas.
